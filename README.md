# website-saya

# 📘 Tugas Praktik 1 - Website HTML Sederhana

## 📝 Deskripsi

Project ini merupakan tugas praktik 1 yang bertujuan untuk membuat website sederhana menggunakan HTML. Website terdiri dari 2 halaman utama:

* Halaman **Selamat Datang (Home)**
* Halaman **Biodata Mahasiswa**

Website ini dibuat sebagai latihan dasar dalam memahami struktur HTML, navigasi antar halaman, dan pembuatan tabel.

---

## 🌐 Halaman Website

### 1. Halaman Utama (`index.html`)

Berisi:

* Judul **Selamat Datang**
* Deskripsi singkat website
* Nama mahasiswa
* Link menuju halaman biodata

---

### 2. Halaman Biodata (`biodata.html`)

Berisi:

* Judul **Biodata Saya**
* Foto mahasiswa
* Informasi:

  * Nama
  * Umur
* Tabel **Riwayat Pendidikan**
* Tombol kembali ke halaman utama

---

## 🛠️ Teknologi yang Digunakan

* HTML5
* CSS (internal)
